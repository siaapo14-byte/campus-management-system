# 校园管理系统 - 微信小程序端

## 项目概述

这是校园管理系统的微信小程序端，为学生提供便捷的移动端服务，包括成绩查询、课程管理、成绩分析等功能。

## 功能特性

### 🔐 用户登录
- **微信快速登录**：通过微信小程序授权机制快速登录
- **学号密码登录**：支持传统学号密码登录方式
- **自动登录**：登录状态持久化，无需重复登录

### 📊 成绩查询
- **详细成绩列表**：展示所有课程成绩详情
- **智能搜索**：支持课程名称、教师姓名搜索
- **多维度筛选**：按分数范围、课程类型筛选
- **统计概览**：总课程数、平均分、及格率等关键指标

### 📈 成绩分析
- **雷达图分析**：直观展示各科成绩优势和劣势
- **分布饼图**：成绩分布情况可视化
- **对比柱状图**：与班级平均分对比分析
- **趋势分析**：学习状态评估和建议
- **智能建议**：基于成绩数据生成个性化学习建议

### 📚 课程管理
- **课程列表**：查看可选课程和已选课程
- **选课功能**：在线选课操作
- **退课功能**：课程退选管理

## 开发环境配置

### 1. 域名配置问题解决

**问题**：`http://localhost:5000 不在以下 request 合法域名列表中`

**解决方案**：

#### 开发环境（推荐）
1. 打开微信开发者工具
2. 点击右上角"详情"按钮
3. 选择"本地设置"选项卡
4. **勾选"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"**

#### 生产环境
1. 修改 `config.js` 文件中的 `currentEnv` 为 `'production'`
2. 将 `production.baseUrl` 修改为实际域名
3. 在微信小程序管理后台配置合法域名

### 2. 环境配置

项目支持开发和生产环境配置：

```javascript
// config.js
const currentEnv = 'development'; // 开发时使用
// const currentEnv = 'production'; // 部署时使用
```

## API接口

### 认证接口
- `POST /api/auth/login` - 学号密码登录
- `POST /api/auth/wechat_login` - 微信登录

### 学生接口
- `GET /api/student/info` - 获取学生信息
- `GET /api/student/grades` - 获取成绩列表
- `GET /api/student/courses` - 获取课程列表
- `GET /api/student/analysis` - 获取分析数据

### 课程接口
- `POST /api/student/select_course` - 选课
- `POST /api/student/drop_course` - 退课

## 开发说明

### 环境要求
- 微信开发者工具
- 微信小程序基础库 2.10.4+
- 后端服务运行在 localhost:5000

### 开发步骤
1. 克隆项目到本地
2. 使用微信开发者工具打开项目
3. **配置开发环境域名设置**（重要！）
4. 确保后端服务正常运行
5. 配置小程序AppID（如需要）
6. 开始开发调试

### 注意事项
- **开发时必须勾选"不校验合法域名"选项**
- 确保后端API服务正常运行
- 注意网络请求的跨域配置
- 遵循微信小程序开发规范
- 注意数据安全和用户隐私保护

### 部署说明
1. 修改 `config.js` 中的环境配置
2. 配置生产环境域名
3. 在微信小程序管理后台添加合法域名
4. 上传代码并发布
